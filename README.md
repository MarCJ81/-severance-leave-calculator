# 퇴직금·연차 계산기

대한민국 근로기준법·근로자퇴직급여 보장법 기준의 모바일용 계산기 웹앱입니다.
`index.html` 하나로 동작하며 외부 CDN·서버·빌드가 필요 없습니다.

- 웹앱: https://marcj81.github.io/-severance-leave-calculator/

## 계산 기준
- **연차**: 1년 미만 월 개근 1일(최대 11일), 1년 이상 15일, 3년 차부터 매 2년마다 1일 가산(총 25일 한도). 입사일 기준·회계연도 기준을 함께 계산하고 퇴사 정산일수를 비교합니다.
- **퇴직금**: 재직 365일 이상, 퇴사일 포함 직전 3개월 평균임금 기준. 1일 평균임금과 1일 통상임금 중 큰 금액을 적용(근로기준법 제2조 제2항)하고 적용 근거를 화면에 표시합니다.
- 연차수당: 잔여일수 × 1일 통상임금(월 통상임금 ÷ 209 × 8).

## 한계
- 연차는 개근을 가정합니다. 실업·휴직 등 평균임금 산정 제외기간, 퇴직소득세, 비과세 수당은 반영하지 않습니다.
